# My Portfolio 

This is the repository for my personal portfolio website, hosted for free via [GitHub Pages](https://martimconceicao.github.io/portfolio/).

## 🌐 Website Link
You can visit the live website here: 
**[https://martimconceicao.github.io/portfolio/](https://martimconceicao.github.io/portfolio/)**

## 📁 Project Structure

The code has been organized to keep the source files separate from images and other visual assets:

* **`/Ficheiros/`** - Contains the main website code (`Martim.html`, `Martim.css`, and `Martim.js`).
* **`/Anexos/`** - Contains all images, audio files (mp3), and logos used on the page.
* **`index.html`** - Root file configured to automatically redirect visitors to the main page.
